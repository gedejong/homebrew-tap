# gedejong/homebrew-tap

Homebrew formulae for [mtr-ng](https://github.com/gedejong/mtr-ng), a traceroute and ping tool with a terminal UI.

```sh
brew install gedejong/tap/mtr-ng
```

`Formula/mtr-ng.rb` is written by mtr-ng's release workflow; changes made here are overwritten by the next release.
